# Sistema Inteligente de Monitoramento de Estacionamento

Este projeto utiliza técnicas de **Visão Computacional** e **Aprendizado de Máquina** para monitorar vagas de estacionamento em tempo real, identificando automaticamente quais estão ocupadas ou disponíveis.

## 🚀 Sobre o Projeto
O sistema processa fluxos de vídeo (de câmeras de segurança ou arquivos gravados) para determinar o status das vagas de um estacionamento. O objetivo principal é otimizar a gestão de espaço, reduzindo o tempo que motoristas levam para encontrar uma vaga disponível.

## 🛠 Tecnologias Utilizadas
*   **Python**: Linguagem principal do projeto.
*   **OpenCV**: Manipulação de imagens e processamento de vídeo.
*   **NumPy**: Processamento de matrizes e cálculos.

## 📋 Funcionalidades
*   **Detecção em Tempo Real**: Identificação instantânea de veículos.
*   **Contagem Dinâmica**: Atualização automática do contador de vagas livres vs. ocupadas.
*   **Interface Visual**: Marcação gráfica das vagas (ex: Verde para livre, Vermelho para ocupado).
